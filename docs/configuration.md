# Configuration

DevNexus uses XDG-compliant paths for all managed files. This document describes the directory layout and configuration files.

---

## Data Directory

All DevNexus data lives in a platform-specific location:

| Platform | Path |
|----------|------|
| **Linux** | `~/.local/share/dev-stack/` |
| **macOS** | `~/Library/Application Support/dev-stack/` |
| **Windows** | `%APPDATA%/dev-stack/` |

---

## Directory Structure

```

├── bin/                     # Tool binaries
│   ├── php/                 # PHP versions
│   │   ├── 8.2.15/

│   ├── mysql/               # MySQL versions

│   ├── redis/               # Redis
│   ├── mailpit/             # Mailpit
│   └── postgres/            # PostgreSQL
│
├── config/                  # Configuration files
│   ├── Caddyfile            # Generated Caddy config
│   ├── my.cnf               # MySQL config (my.ini on Windows)
│   ├── php/
│   │   ├── php.ini          # PHP config (global fallback)
│   │   └── fpm/             # Per-site PHP-FPM pool configs
│   │       ├── my-app.conf
│   │       └── blog.conf
│   ├── redis.conf           # Redis configuration
│   ├── postgresql.conf      # PostgreSQL configuration
│   └── sites/               # Per-site vhost configs
│
├── data/                    # Runtime data
│   ├── mysql/               # MySQL data directory
│   └── redis/               # Redis data (dump.rdb)
│
├── logs/                    # Service logs
│   ├── caddy.log
│   ├── mysql.log
│   └── php-fpm.log
│
├── tmp/                     # PID files
│   ├── caddy.pid
│   ├── mysql.pid
```

## Configuration Files

### `app_config.json`

Main application configuration:

```json
{
  "php_version": "8.3.4",
  "auto_start_services": true,
  "default_site_type": "laravel",
  "theme": "dark"
}
```

### `mcp_config.json`

MCP server settings:

```json
{
  "enabled": false,
  "port": 8938,
  "token": "devnexus-xxxxxxxxxxxx"
}
```

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `enabled` | bool | `false` | Whether the MCP server is active |
| `port` | number | `8938` | HTTP port for the MCP endpoint |
| `token` | string | auto-generated | Bearer token for authentication |

### `Caddyfile`

Auto-generated by DevNexus. **Do not edit manually** — changes are overwritten on the next reload.

```caddy
my-app.test {
    root * /home/user/www/my-app/public
    php_fastcgi unix//tmp/php-fpm-my-app.sock
    file_server
}

blog.test {
    root * /home/user/www/blog
    php_fastphp unix//tmp/php-fpm-blog.sock
    file_server
}

node-app.test {
    reverse_proxy localhost:3000
}
```

### `my.cnf` / `my.ini`

MySQL configuration:

```ini
[mysqld]
datadir=/home/user/.local/share/dev-stack/data/mysql
port=3306
socket=/tmp/mysql.sock
no-defaults
skip-grant-tables
```

### Per-Site PHP-FPM Pool

Located in `config/php/fpm/<site-name>.conf`:

```ini
[my-app]
listen = /tmp/php-fpm-my-app.sock
listen.allowed_clients = any
user = nobody
group = nobody
pm = dynamic
pm.max_children = 5
pm.start_servers = 2
pm.min_spare_servers = 1
pm.max_spare_servers = 3
php_admin_value[error_log] = /home/user/.local/share/dev-stack/logs/php-fpm-my-app.log
```

### Per-Site `.devnexus.json`

Optional project-level configuration (see [Sites & Projects](./sites.md)):

```json
{
  "type": "laravel",
  "domain": "custom-domain.test",
  "php_version": "8.3",
  "document_root": "public",
  "node_port": 3000
}
```

## Shell Integration

DevNexus injects its binary paths into your shell configuration:

| Shell | Config File |
|-------|------------|
| Bash | `~/.bashrc` |
| Zsh | `~/.zshrc` |

**Injected paths:**

```bash
# DevNexus PATH injection
export PATH="$HOME/.local/share/dev-stack/bin/php/8.3.4:$PATH"
export PATH="$HOME/.local/share/dev-stack/bin/caddy:$PATH"
export PATH="$HOME/.local/share/dev-stack/bin/mysql:$PATH"
```

---

## System Integration

### `/etc/hosts`

DevNexus adds entries for all discovered sites:

```
127.0.0.1  my-app.test
127.0.0.1  blog.test
```

### SSL Certificate Store

Caddy's root CA is injected into the system certificate store:

| Platform | Method |
|----------|--------|
| Linux | `update-ca-certificates` |
| macOS | Keychain |
| Windows | PowerShell `Import-Certificate` |

### System Tray

DevNexus adds a system tray icon with quick controls:

- Start/stop all services
- Open Dashboard
- Quit

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `RUST_LOG` | `info` | Log level for backend |
| `DEV_STACK_DIR` | (platform default) | Override data directory |
